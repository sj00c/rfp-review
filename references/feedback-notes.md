# 구매팀 피드백 사례의 사용 범위

2026-11-05 첨부 메모를 부모 Agent가 ZIP 내 HWPX XML에서 확인한 사례 요약이다. 실제 사업명·문서 원문·예산은 복제하지 않는다. 이 파일은 검토 맥락과 회귀 사례를 설명하며 **법적 판정 근거가 아니다**. 공식 기준은 별도 출처·판본·적용 범위를 확인한다.

| 사례 | 지적하면 안 되는 상황 | 확인하거나 지적할 상황 |
|---|---|---|
| 기술 배점 | 정량·정성 합계 100점을 최종 기술 비중으로 환산하는 정상 구조 | 실제 세부합계 오류, 적용 모드와 최종 배점 불일치 |
| 기관 운영 | 기관의 90:10·80:20 모드를 보편적 위반으로 단정 | 이번 사업에 적용되는 모드와 공식 기준이 미확인 또는 상충 |
| 공동계약 | 현재 공동입찰 불허를 이유로 과거 공동계약 실적의 지분 증빙 삭제 | 현재 참가조건 자체가 문서 간 허용/불허로 충돌 |
| 산식 | 수식/그림이 추출되지 않았다는 이유만으로 공란 판정 | 실제 읽은 비율이 적용 기준과 다름. 읽지 못했으면 확인필요 |
| 설명회 | 필요 시 별도 통보라는 문구만으로 삭제·일정 누락 지적 | 실제 의무 참석 조건과 일정·참가권한 등이 충돌 |
| 퇴직자 서식 | 기관 공통 확인서 존재만으로 삭제 요구 | 사업별 추가 서식·감점 조건의 근거와 실제 모순 확인 |
| 기간·예산 | 다른 기간 의미·금액 범위를 무조건 비교 | 용역계약의뢰서 등 같은 범위 문서의 실질 불일치 |
| 평가 설계 | 같은 단어가 등장하지만 측정대상·증빙이 다른 평가 | 같은 실적을 정량·정성에서 실제 이중 평가하거나 판단기준이 없음 |
| 실적 평점 | 최저 70% 의견을 모든 기관·사업의 법적 기준으로 적용 | 적용이 확인된 기관 기준 이탈, 배점표와 상세기준의 실제 불일치 |

SW e-제안요청 도움 보고서는 자체적으로 오탐 가능성과 비절대성을 밝힌 참고자료다. 보고서 지적을 원문 확인 없이 복제하지 않는다. 용역 분류별 업종코드·중소기업 경쟁제품 목록은 제공 예정이므로 없는 목록을 만들거나 예시를 실제 목록으로 사용하지 않는다.

## 의미 검증

정상 과거 실적/실제 현재 참가조건 충돌, 서로 다른 평가대상/같은 실적 이중평가를 각각 합성 문서쌍으로 실행한다. Agent에는 원문과 기준만 제공하고 정답 findings는 제공하지 않는다. 별도 평가자가 실제 출력의 금지 오탐·필수 지적·근거·두 위치 인용·조치 대상을 확인한다. Python 테스트가 수작성 JSON을 검증한 것만으로 Agent의 문맥 판단 성공을 주장하지 않는다.
