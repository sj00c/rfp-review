# 제안요청서·공고문 검토 체크리스트

원본: 입찰 업무 체크리스트 v4 (26.8. 기준, 감사원 공공계약 실무가이드 2024 반영). 근거란의 p.는 실무가이드 쪽수.

- ID: `시트번호-항목번호` (예: ②-2). ②시트는 원본의 [n] 번호를 그대로 쓴다(19·26번은 원본에 없음).
- 중요도: ★필수 = 법령·계약예규상 필수, 확인 = 실무 필수, 참고 = 경미.
- 판정방식: [문서] 문서 내용으로 판정 / [계산] `scripts/check_numbers.py`로 판정 / [확인] 문서만으로 판정 불가 → '확인필요'로 분류하고 확인할 내용을 적는다.
- 연계: `↔ ②-n`은 함께 점검할 항목. 같은 문제는 결과표에 한 번만 쓰고 연계 ID를 같이 적는다.
- 임계값은 항상 부가세 제외 추정가격 기준, 공고일(재공고 시 최초 공고일) 현행 법령 기준.
